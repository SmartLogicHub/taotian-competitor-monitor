# 淘天竞品监控控制台

一个 Windows 本地工具：点击 EXE 后启动本地网页控制台，上传带商品链接的 Excel，低频打开淘宝/天猫详情页，把耳机形态写入 D 列、详情页显示价写入 E 列，并输出一个补全副本。

## 使用流程

```powershell
python -m taotian_price_tool
```

启动后会自动打开本地页面，通常是：

```text
http://127.0.0.1:17888
```

操作顺序：

1. 点击 `打开登录浏览器`，在工具专用浏览器里扫码登录淘宝。
2. 登录完成后回到控制台，上传 C 列包含商品链接的 `.xlsx` 表格。
3. 在 `本机设置` 中保存 DeepSeek API Key 和采集强度。
4. 点击 `开始低频采集`。
5. 完成后点击 `打开结果文件`。
6. 需要反馈错误时，点击 `复制日志` 或 `复制最后错误`，直接粘贴给开发者排查。

工具会复用 `%APPDATA%\TaotianPriceTool\browser-profile` 里的登录态。开始采集前会自动释放登录窗口，避免采集浏览器和登录浏览器同时占用同一个 Chromium 配置目录。

## Excel 规则

- C 列：淘宝/天猫商品详情链接。
- D 列：耳机形态。
- E 列：详情页显示价。
- 原文件不会被覆盖；结果保存为新的 `已补全` 副本。

耳机形态固定为六类：`半入耳`、`入耳式`、`耳夹式`、`头戴式`、`挂脖式`、`挂耳式`。工具不会输出 `未知` 或 `待确认`。

## 风控安全边界

- 默认 `保守` 模式：单线程，8-20 秒/条。
- 只访问用户上传表格里的商品详情链接。
- 不做搜索、不扫店铺、不爬推荐页。
- 遇到登录、短信验证、身份验证、滑块等页面会暂停，等待人工处理。
- 不做代理池、IP 切换、验证码绕过、设备指纹伪装或淘宝内部接口批量请求。
- 低频和人工协作只能降低异常访问风险，不能保证 100% 不触发平台风控或账号限制。

## 打包 EXE

```powershell
.\build_exe.ps1
```

脚本会自动安装依赖、安装 Playwright Chromium，并把 Chromium 浏览器目录一起打进 EXE 目录。

输出目录：

```text
dist\淘天竞品监控控制台
```

## 测试

```powershell
python -m unittest discover -s tests
python -m compileall -q taotian_price_tool tests run_app.py
```
